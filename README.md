# VANTOX — مولّد سيناريوهات الستوري

Viral Story & Poll Script Generator for Instagram / TikTok / Facebook creators.

Domain: **https://vantox.store**

## Features

- اختيار المجال (جيمنج، تقنية، لايف ستايل، …)
- أنواع الستوري: هذا أم ذاك، سلسلة 3 خطوات، Q&A، جدل يومي
- معاينة حية 9:16 + ألوان + رفع خلفية
- نسخ النص / تحميل PNG
- تريند اليوم + عداد الاستمرار (Streak)

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy (Vercel)

Repo already linked as `vantox-store`. Push to `main` to redeploy.
Env vars from the old storefront (`NEXT_PUBLIC_SUPABASE_*`) are optional for this version — ideas run locally in the browser.
